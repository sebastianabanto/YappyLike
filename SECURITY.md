# Security policy

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities. Report them
privately through GitHub's security advisories for this repository.

If a credential is ever committed by mistake, revoke or rotate it immediately;
removing it from Git history does not invalidate a credential that was already
exposed.

## Local data

YappyLike processes selected text locally. Runtime configuration, logs, downloaded
models, and generated artifacts should remain outside version control.
